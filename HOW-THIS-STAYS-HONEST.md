# How this stays honest

Every official version of the HI Accords is permanent, public, and checkable, so no one can quietly change it, including the people who maintain it.

## Every version is permanent

Each official version is published on Zenodo, a free public repository run by CERN. Each one gets a permanent identifier (a DOI), and once published, it can't be altered. New versions are added alongside old ones, never in place of them. [Link to Zenodo record]

## Every change is visible

The working text lives here on GitHub, where every edit is logged with who made it and when. Anyone can propose a change in the open. Nothing changes quietly.

## You can check any copy

Each official version has a digital fingerprint, a short code that changes if even one character of the text changes. If the code on a copy you find doesn't match the one below, it isn't the real version. Each version is also timestamped, so its date can be proven.

## How suggestions become changes

1. Anyone can submit a suggestion on Pol.is and vote agree, disagree, or pass on others. [Join the discussion](https://pol.is/5raxffr2dm)
2. Suggestions that reach broad agreement, across people who otherwise disagree, are considered for the next version.
3. Each new version comes with a changelog saying what changed and why.
4. Contributors are credited, and nothing is removed without explanation.

## Who maintains it

Michael Bilodeau maintains the official text. Every account involved is protected with two-factor authentication. Any change in who maintains it will be announced publicly.
